# PRISM feature map — cinematic redesign

The two user-provided video references guide the visual treatment: a large metallic sphere composition, condensed oversized type, restrained navigation, and a second fractured cyan core. The 3D objects are original procedural geometry and materials, not extracted video assets.

| Feature | Location |
| --- | --- |
| Interactive 3D cluster and fractured core | Experience |
| Rotate, zoom, disassemble, pause and reset | Experience controls |
| Traffic multipliers and capacity calculation | Simulator |
| Dependency failure injection | Simulator and service inspector |
| Budget constraints | Simulator |
| Editable baseline, capacity and all monthly cost assumptions | Model settings |
| Draggable architecture graph, dependency connections, zoom and fit | Architecture |
| Hover blast-radius preview | Architecture |
| Current/proposed compute topology | Architecture |
| Selected-service details and targeted failure | Architecture inspector |
| Demand, capacity, utilization and deficit | Analysis |
| Current/proposed cost and delta | Analysis |
| Deterministic line-by-line math | Analysis |
| Bedrock explanation or clearly labeled deterministic fallback | Analysis |
| Full decision record, copy and Markdown export | Analysis |
| Saved runs, search and scenario filters | Archive |
| Two-run comparison and reopening prior evidence | Archive |
| Loading, retryable failures and preserved previous results | Simulator and global notification |
| Browser persistence and malformed-history recovery | Archive |
| Reduced motion and phone layout | All views |
| Model limitations and AWS integration status | Guide, Analysis and Model settings |

The Python engine, Lambda adapter, optional Bedrock integration and SAM template remain intact. No AWS deployment is part of this redesign.
